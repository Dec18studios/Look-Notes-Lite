# Look Notes Lite

Free OFX plugin for DaVinci Resolve. Burn a look's label and notes into the image so clients always know which look they're watching, and flip between look nodes from one menu.

## Download

- [macOS (universal)](https://github.com/Dec18studios/Look-Notes-Lite/releases/latest/download/LookNotes_Lite_macOS_universal.zip)
- [Windows (CUDA)](https://github.com/Dec18studios/Look-Notes-Lite/releases/latest/download/LookNotes_Lite_windows_cuda.zip)
- [Linux (CUDA)](https://github.com/Dec18studios/Look-Notes-Lite/releases/latest/download/LookNotes_Lite_linux_cuda.zip)

Or install it from the Dec18 Plugin Manager.

## What Lite does

- 3 looks, each with a Label and Notes.
- Garamond or Pixel font, burned straight into the image.
- Node toggling: pick a look and its node turns on, the others turn off.
- Export Current Look saves a JPG of the frame with the look's name and date.

## Look Notes Pro

Pro adds 8 looks, your own fonts, colours, Reframe mode with an image sampled palette, PowerGrade Mode, Export All Looks with a Look Grid, and PNG or 16 bit TIFF stills. It comes with the Dec18 Toolbox membership:
https://tools.dec18studios.com/color-grading-tools/look-notes/

## Install

Unzip and drop LookNotes.ofx.bundle into your OFX plugins folder, then restart Resolve.

- macOS: /Library/OFX/Plugins
- Windows: C:\Program Files\Common Files\OFX\Plugins
- Linux: /usr/OFX/Plugins

Lite and Pro install the same bundle, so remove one before installing the other.
